# Machine Learning Zoomcamp

My coursework for [DataTalksClub’s Machine Learning Zoomcamp](https://github.com/DataTalksClub/machine-learning-zoomcamp), completed through **Module 05 — Model Deployment**.

- **01 — Introduction to Machine Learning:** ML fundamentals and the model development workflow.
- **02 — Regression:** Training and evaluating models for numerical predictions.
- **03 — Classification:** Data preparation, feature engineering, and logistic regression.
- **04 — Evaluation Metrics:** Precision, recall, ROC AUC, and cross-validation.
- **05 — Model Deployment:** Serving a prediction model through a Flask API, packaging it with Docker, and deploying it to AWS Elastic Beanstalk.
