# Machine Learning Zoomcamp

My coursework for [DataTalksClub’s Machine Learning Zoomcamp](https://github.com/DataTalksClub/machine-learning-zoomcamp), completed through **Module 08 — Neural Networks and Deep Learning**.

- **01 — Introduction to Machine Learning:** ML fundamentals and the model development workflow.
- **02 — Regression:** Training and evaluating models for numerical predictions.
- **03 — Classification:** Data preparation, feature engineering, and logistic regression.
- **04 — Evaluation Metrics:** Precision, recall, ROC AUC, and cross-validation.
- **05 — Model Deployment:** Serving a prediction model through a Flask API, packaging it with Docker, and deploying it to AWS Elastic Beanstalk.
- **06 — Decision Trees and Ensemble Learning:** Comparing decision trees, random forests, and XGBoost for vehicle fuel-efficiency prediction using validation RMSE, tuning model hyperparameters, and analysing feature importance.
- **08 — Neural Networks and Deep Learning:** Building a PyTorch CNN to classify straight and curly hair, training a 10-epoch CPU baseline, and continuing for 10 more epochs with image augmentation. Recorded training and held-out loss and accuracy after each epoch.
